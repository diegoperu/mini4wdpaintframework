# Technical Terminology

**Document ID:** KNW-TRM-001
**SDK Version:** 2.3.0
**Category:** Terminology Reference

---

## Purpose

Defines technical terms used in the SDK and their correct Italian equivalents. Complements `Knowledge/GlossaryIT.md` (which lists approved terms) by providing context, etymology, and usage rules for less common or ambiguous terms.

---

## Paint Chemistry Terms

| English Term | Italian Term | Usage Notes |
|-------------|-------------|-------------|
| Lacquer | Lacca | Use for Tamiya TS and Mr. Color C series |
| Acrylic | Acrilico | Use for Tamiya X/XF and Vallejo series |
| Enamel | Smalto | General term; distinct from "acrilico" |
| Thinner | Diluente | Generic; use specific brand name where possible |
| Solvent | Solvente | More technical than "diluente" |
| Binder | Legante | Polymer that holds pigment — rarely used in manuals |
| Pigment | Pigmento | Color component of paint |
| Vehicle | Veicolo | Carrier for pigment — rarely used in manuals |
| Flash time | Tempo di evaporazione | Time between coats |
| Pot life | Tempo di utilizzo | Time paint remains usable after mixing |

## Surface Terms

| English Term | Italian Term | Usage Notes |
|-------------|-------------|-------------|
| Polycarbonate | Policarbonato | Preferred over "PC" or "Lexan" |
| ABS plastic | Plastica ABS | Both terms acceptable; "ABS" is industry standard |
| Sprue | Sprue | No standard Italian term; use *sprue* in italic |
| Gate | Gate | No standard Italian term; use *gate* in italic |
| Mold seam | Linea di stampaggio | Not "mold line" |
| Surface defect | Difetto superficiale | Not "imperfezione" alone |
| Sink mark | Segno di ritiro | Concave defect from plastic shrinkage |
| Flash | Bava | Thin excess plastic at parting line |

## Process Terms

| English Term | Italian Term | Usage Notes |
|-------------|-------------|-------------|
| Base coat | Mano di fondo / Colore base | Context-dependent |
| Top coat | Finitura / Vernice di finitura | Not "top coat" |
| Clear coat | Vernice trasparente | Not "clear coat" |
| Primer | Primer | Accepted as-is; no standard Italian equivalent |
| Wet sanding | Carteggiatura a umido | Not "wet sanding" |
| Dry sanding | Carteggiatura a secco | — |
| Masking | Mascheratura | Not "masking" |
| Overcoat | Mano successiva | Context-dependent |
| De-masking | Rimozione della mascheratura | Not "de-masking" or "unmasking" |

## Quality / Defect Terms

| English Term | Italian Term | Usage Notes |
|-------------|-------------|-------------|
| Orange peel | Buccia d'arancia | Texture defect from incorrect spraying |
| Fish eye | Occhio di pesce | Circular crater from surface contamination |
| Run / Drip | Colatura | Paint that flows before drying |
| Bleed | Infiltrazione | Paint seeping under masking tape |
| Silvering | Effetto argento | Decal defect: trapped air |
| Crazing | Screpolatura | Crack network from solvent attack |
| Lifting | Distacco | Paint peeling during tape removal |
| Dry spray | Verniciatura asciutta | Grainy texture from incorrect distance |
