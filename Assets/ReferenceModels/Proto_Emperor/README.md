## Model Description

The Proto Emperor is a Tamiya Mini4WD racing car model in the Super-2 chassis format. Key visual features:

- Low-profile body with aggressive aerodynamic lines
- Prominent rear wing with multi-element design
- Triangular side skirt profile
- Front cowl with integrated air channel
- Clear polycarbonate body (undecorated stock configuration)
