# OperatorGuide/

**A cosa serve questa cartella:** guida completa per l'Operatore — la persona che usa
l'SDK per produrre manuali senza conoscerne gli inner working. Sette documenti, in
ordine di lettura.

**Chi la modifica:** Developer, solo in fase di release SDK.
**Quando:** mai durante un progetto; l'Operatore la legge, non la modifica.
